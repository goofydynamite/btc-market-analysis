# Bitcoin Market Intelligence

Analysis of 14 years of one-minute BTC/USD data (Bitstamp, 2012–2026) to answer product, risk and operations questions for a retail crypto-investing app.

**Status:** work in progress.

## Data

[Kaggle: Bitcoin Historical Data](https://www.kaggle.com/datasets/mczielinski/bitcoin-historical-data), one-minute OHLCV bars (~7.8M rows, 394 MB). The raw CSV is not committed.

Download `btcusd_1-min_data.csv` and place it in `data/raw/`.

## Setup

```bash
pip install -r requirements.txt
```
